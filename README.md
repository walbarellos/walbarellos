## Sobre

Sou desenvolvedor de software e gosto de entender como as coisas funcionam por dentro. Trabalho com aplicações web, ferramentas de análise, automação, sistemas institucionais e projetos experimentais.

Entre meus interesses estão OSINT, dados públicos, engenharia reversa, segurança e acessibilidade. Também desenvolvo aplicativos Android e jogos independentes.

Tenho projetos próprios, adaptações de projetos existentes e sistemas institucionais que não podem ser divulgados publicamente. Aqui estão alguns dos trabalhos que posso apresentar.
