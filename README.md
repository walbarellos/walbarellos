## Sobre

Engenheiro de software e criador de sistemas. Desenvolvo tecnologia assistiva e acessibilidade digital (proposta selecionada na 1ª fase do Programa Centelha/FINEP), sistemas para transparência pública e inteligência cívica sobre dados abertos, engines gráficas procedurais (Fourier e Perlin em C++) e módulos nativos de sistema operacional para Linux (C++20, Wayland, ELF 64-bit).

Foco em arquiteturas robustas, offline-first, performance nativa e conformidade estrita (WCAG / LBI).
